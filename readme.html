✧ 档案保护大冒险

单人闯关 · 72 格长线探险 · 守护记忆

目标：拥有 3 点档案耐久，抵达第 72 格终点！

📱 手机端特别提示：
棋盘较大，在手机上可以左右滑动查看全貌。为了避免忘记操作，游戏界面下方会有一个悬浮提示条，告诉你当前该做什么（比如“点击掷骰子”或“点击抽卡”）。

🎲 核心玩法：每回合 3 步

  • 1
    选择策略并掷骰
    掷骰前，先选稳妥、探查或冒险。点击“🎲 掷骰子”前进。
  • 2
    处理脚下格子
    停在哪个格，就按提示处理。如果是卡牌格，一定要记得点击「抽取当前格卡牌」！
  • 3
    结算移动并结束回合
    答对、答错或遇到事件后，系统会弹窗告诉你“前进/后退几格”，点击确认后本回合结束，开始下一回合。

🗺️ 四类卡牌与格子

📖 知识 四选一。答对按难度前进并加连对，答错会扣耐久并后退。

⚠️ 事件 两难抉择。选安全项可能后退，选冒险项可能前进但扣血。

🛡️ 保护 收入背包。在关键时机（如即将后退时）点击侧边栏的“使用”来抵消惩罚。

🔎 任务 多选题。选出所有正确选项才算完成，完成前进，失败扣耐久后退。

空地/加速/陷阱 直接结算，无答题。加速额外前进，陷阱后退。

⚙️ 策略与难度

🔹 稳妥：正常掷 1-6。

🔹 探查：掷 1-3，若踩到知识或任务格，额外送 1 张保护卡。

🔹 冒险：掷 4-6，但若踩到事件格，所有的负面效果（扣血/后退）翻倍！

* 游戏过程中可以随时在右上角切换难度（轻松/标准/挑战），影响答题奖惩和事件负面幅度。切换不会重置进度。
