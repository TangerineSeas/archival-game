# archival-game
# 档案保护大冒险
## 一、项目简介

《档案保护大冒险》是一款以档案保护为主题的单人网页闯关游戏。游戏以《档案保护概论》相关知识为基础，将档案保存、日常检查、环境控制及保护措施等内容融入棋盘探索、卡牌问答与策略选择之中。

玩家需要在 72 格蛇形路线中不断前进，通过回答知识问题、处理突发事件、完成特殊任务以及合理使用保护行动卡，尽可能在档案耐久耗尽前抵达终点。

本项目采用 HTML、CSS 和 JavaScript 实现，可直接在浏览器中运行，无需安装额外软件或配置服务器。

## 二、游戏目标

玩家从起点出发，探索 72 格棋盘，并通过掷骰子、选择行动策略和处理格子事件推进游戏。

- **通关目标：** 抵达路线终点。
- **失败条件：** 档案耐久降至 0，游戏立即结束。
- **初始耐久：** 3 点。
- **游戏形式：** 单人闯关。

## 三、主要玩法

### 1. 行动策略

每回合掷骰子前，玩家需要选择一种策略。

| 策略 | 掷骰范围 | 特殊效果 |
| --- | --- | --- |
| 稳妥 | 1–6 | 正常掷骰，按点数前进 |
| 探查 | 1–3 | 停在知识或任务格时，额外获得 1 张保护行动卡 |
| 冒险 | 4–6 | 若触发事件的负面效果，相关惩罚加重 |

不同策略在移动范围与风险之间有所区别，玩家可以根据当前进度和耐久状况作出选择。

### 2. 棋盘格与卡牌

游戏棋盘包含知识、事件、保护、任务、空地、加速和陷阱等类型的格子。

游戏设有四类卡牌，共 38 张：

- **知识问答卡（12 张）：** 考查档案保护相关知识。答对可获得前进奖励，答错则后退并可能损失耐久。
- **突发事件卡（10 张）：** 模拟档案保存过程中可能遇到的情况，玩家需根据卡牌内容处理相应效果。
- **保护行动卡（8 张）：** 提供额外移动、抵消后退或免除部分惩罚等帮助，可存入背包并在符合条件时使用。
- **特殊任务卡（8 张）：** 通过档案保护相关问题检验玩家对知识的理解，完成任务可获得奖励，未完成则承担相应惩罚。

卡牌牌堆抽取完毕后会自动重新洗牌，供后续回合继续使用。

### 3. 难度选择

游戏提供三种难度，并支持在游戏过程中切换，切换难度不会重置当前进度。

| 难度 | 知识题答对 | 知识题答错 | 负面事件移动效果 |
| --- | --- | --- | --- |
| 轻松 | 前进 3 格 | 后退 1 格 | 减轻 1 格 |
| 标准 | 前进 3 格 | 后退 2 格 | 按原卡牌效果执行 |
| 挑战 | 前进 3 格 | 后退 3 格 | 加重 1 格 |

答错问题、任务失败及负面事件可能造成档案耐久损失；选择冒险策略时，事件带来的负面效果会进一步加重。

### 4. 连续答题奖励

为鼓励玩家持续学习，游戏设置了连续答对奖励：

- 连续答对 2 道题：额外前进 1 格。
- 连续答对 3 道题：额外前进 2 格，并恢复 1 点档案耐久。
- 答错问题后，连续答对记录清零。

### 5. 保护行动与耐久管理

玩家获得保护行动卡后，可以将其存入行动卡背包，并在规定时机使用。合理运用行动卡能够帮助玩家应对负面事件、减少后退或降低任务失败带来的损失。

档案耐久是游戏中的重要资源。玩家需要在推进路线、获取奖励和规避风险之间作出选择，避免耐久耗尽导致闯关失败。

## 四、项目特色

1. **知识与游戏结合：** 将档案保护知识融入问答、任务和事件情境，使知识学习与游戏进程相结合。
2. **策略选择机制：** 玩家可以根据局势选择不同的行动策略，在移动效率与风险之间作出权衡。
3. **耐久管理机制：** 通过耐久系统体现档案保护的重要性，并增加闯关过程中的挑战。
4. **多难度设置：** 提供不同难度，玩家可以根据自身情况调整挑战强度。
5. **连续答题奖励：** 通过连对机制鼓励玩家持续回答问题，增强游戏的反馈感。
6. **轻量化运行：** 游戏采用网页形式，无需额外安装软件，打开 HTML 文件即可游玩。

## 五、运行方式

1. 下载或取得项目中的 HTML 文件。
2. 使用 Chrome、Edge 等现代浏览器打开该文件。
3. 进入游戏后，选择难度并开始挑战。
4. 按照界面提示选择策略、掷骰子、处理当前格子，并根据游戏反馈继续闯关。

游戏在本地浏览器中运行，无需联网。

## 六、项目文件

- `README.md`：项目说明文档，介绍作业性质、游戏目标、主要机制与运行方式。

## 七、作业说明

本项目为《档案保护概论》相关课程的期中作业，尝试以网页桌游的形式呈现档案保护知识，将知识问答、情境任务、策略选择和资源管理结合起来，使玩家在探索与闯关过程中了解档案保护的基本原则。
